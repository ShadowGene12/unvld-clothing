## 2026-06-01 - Form Accessibility and Focus States\n**Learning:** Icon-only buttons and forms without visible labels frequently miss necessary accessibility attributes in React components, while default Tailwind input styles often lack strong keyboard focus indicators on dark backgrounds.\n**Action:** Always verify form inputs have associated labels (using `sr-only` if visually hidden), icon buttons have `aria-label`, and interactive elements use `focus-visible` with appropriate ring offsets for keyboard accessibility.
