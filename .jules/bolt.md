## 2026-06-10 - Optimize Array Operations in React Render\n**Learning:** Expensive array operations like map, flatMap, and Set inside functional React component bodies lead to O(N) recalculations on every render. If these operations are performed on statically imported mock data, they should be pre-computed at the module level outside the component.\n**Action:** Always look for loops and array manipulations on static data inside React component scopes and move them out to the file scope to reduce CPU overhead and improve frame rates.
