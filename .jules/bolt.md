## 2024-05-24 - Unmemoized Derived Filter State **Learning:** Computing unique filter options (like categories, sizes, and colors) directly in the component body using Set and map/flatMap on a static data source causes expensive array operations to run on every single render, even when the underlying data hasn't changed. **Action:** Move computation of derived data that only depends on static imports (or use useMemo if depending on props) outside the component body to ensure it is only calculated once upon initialization.
