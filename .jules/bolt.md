## 2024-05-18 - Expensive array operations in React functional component body
**Learning:** The `Shop.tsx` page computes `categories`, `sizes`, and `colors` on every render by mapping over the entire `products` array and constructing new Sets (O(N) operations where N is the number of products/sizes/colors). This causes unnecessary performance overhead during re-renders, such as when updating filters or handling inputs, especially as the product catalog grows.
**Action:** Move static array calculations derived from constants/mock data (like extracting unique categories, sizes, and colors) to the module scope outside of the component body. This ensures they are calculated only once when the file is evaluated, preventing expensive O(N) operations on every component re-render.
