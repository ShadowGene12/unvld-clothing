## 2023-10-26 - Add keyboard accessibility to hover-based dropdown menus\n**Learning:** When adding accessibility to custom hover-based components (like dropdown menus) that previously relied solely on mouse events (`onMouseEnter`/`onMouseLeave`), it is essential to implement an `onClick` toggle and an `onFocus` handler (to open on keyboard Tab) alongside explicit `focus-visible` styles and appropriate ARIA attributes (`aria-expanded`, `aria-controls`). Using `if (!e.currentTarget.contains(e.relatedTarget))` in the `onBlur` handler correctly determines when focus has moved entirely outside the component.\n**Action:** Use this pattern for all hover-based dropdowns or interactive elements to ensure full keyboard navigation support and screen reader compatibility.
