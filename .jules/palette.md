## 2024-05-18 - Added Accessibility to Worlds Dropdown Menu
**Learning:** When building custom hover-based dropdown menus (e.g. relying on onMouseEnter/onMouseLeave), they are not accessible via keyboard or touch devices by default. You need to implement an onClick toggle that includes e.preventDefault() (to prevent touch devices from instantly closing it after the simulated mouseenter), an onFocus handler (to open on keyboard Tab), and an onBlur handler (e.g. checking if e.currentTarget.contains(e.relatedTarget) to close when focus moves away) alongside explicit focus-visible styles and appropriate ARIA attributes (aria-expanded, aria-haspopup, aria-controls).
**Action:** Always ensure hover-based interactions also support keyboard focus and touch devices using ARIA roles and state attributes.
