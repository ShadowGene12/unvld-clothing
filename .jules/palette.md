## 2024-03-20 - Header Dropdown Accessibility
**Learning:** Dropdowns that rely solely on `onMouseEnter` / `onMouseLeave` break keyboard navigation. Users tabbing through the nav get stuck or skip the dropdown items. Touch devices can also act inconsistently.
**Action:** When adding accessibility to custom hover-based components (like dropdown menus) that previously relied solely on mouse events (`onMouseEnter`/`onMouseLeave`), ensure you implement an `onClick` toggle that includes `e.preventDefault()` (to prevent touch devices from instantly closing it after the simulated `mouseenter`), an `onFocus` handler (to open on keyboard Tab), and an `onBlur` handler (e.g., checking if `e.currentTarget.contains(e.relatedTarget)` to close when focus moves away) alongside explicit `focus-visible` styles and appropriate ARIA attributes (`aria-expanded`, `aria-haspopup`, `aria-controls`).
