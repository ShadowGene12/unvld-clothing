## 2023-10-26 - Accessible Custom Dropdown Menus
**Learning:** When adding accessibility to custom hover-based components (like dropdown menus) that previously relied solely on mouse events (`onMouseEnter`/`onMouseLeave`), ensure you implement an `onClick` toggle that includes `e.preventDefault()` (to prevent touch devices from instantly closing it after the simulated `mouseenter`), an `onFocus` handler (to open on keyboard Tab), and an `onBlur` handler (e.g., checking if `e.currentTarget.contains(e.relatedTarget)` to close when focus moves away) alongside explicit `focus-visible` styles and appropriate ARIA attributes (`aria-expanded`, `aria-haspopup`, `aria-controls`).
**Action:** Always test hover-based UI components with keyboard navigation (Tab/Enter) and ensure they have full ARIA attribute coverage and explicit focus states.
