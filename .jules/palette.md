## 2023-10-25 - ARIA Disclosure Pattern for Hover Menus
**Learning:** When migrating a navigation dropdown from a purely hover-based interaction (`onMouseEnter`/`onMouseLeave`) to an accessible one, simply adding a keyboard event isn't enough. Screen readers need to know about the toggle state and its target (using `aria-expanded` and `aria-controls`), and keyboard users rely on focus logic. Managing `onBlur` on the container, specifically using `!e.currentTarget.contains(e.relatedTarget)` to detect focus leaving the entire component, is a critical pattern for robust dropdown accessibility.
**Action:** Always implement the full ARIA Disclosure pattern (button with `aria-expanded`/`aria-controls` + `onClick` + focus management) alongside `onMouseEnter`/`onMouseLeave` when building or fixing hover-based menus to support both pointer and keyboard users seamlessly.
