## 2024-10-03 - Keyboard Accessibility for Hover-based Dropdowns
**Learning:** Hover-based dropdown menus in this application's layout frequently lack corresponding keyboard interaction patterns. Relying solely on `onMouseEnter`/`onMouseLeave` excludes keyboard users and screen readers from accessing nested navigation items like the "Worlds" menu.
**Action:** When implementing or fixing hover-based dropdowns, always include an explicit `onClick` toggle on the button, an `onFocus` handler on the container to open via Tab navigation, and an `onBlur` handler (checking `!e.currentTarget.contains(e.relatedTarget)`) to close when focus moves outside. Ensure ARIA attributes (`aria-expanded`, `aria-haspopup`, `aria-controls`) and custom `focus-visible:ring-2` styles are applied to maintain focus clarity within the Shadcn UI design system.
