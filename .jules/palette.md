## 2024-05-18 - Keyboard Accessible Dropdown\n**Learning:** When building custom hover-based dropdown menus without external libraries, purely relying on mouse events excludes keyboard-only users, and touch users may experience instant closing. It's critical to include onFocus/onBlur for tab navigation, onClick for toggling with preventDefault() for touch devices, and proper ARIA states.\n**Action:** Always implement a complete set of event handlers (mouse, focus, and click) with explicit focus-visible styles and ARIA attributes for custom interactive widgets like dropdowns.
